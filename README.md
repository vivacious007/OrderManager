# Order Manager PWA

A simple Progressive Web App built with React to manage user input orders and display them in a dashboard.

## Features
- Add order with description and price
- Store orders in localStorage
- View orders with total price
- Fully offline-capable (PWA)

## Getting Started

```bash
npm install
npm start
```

## Build for Production

```bash
npm run build
```

## Deploy

You can deploy it using GitHub Pages, Netlify, or Vercel.
